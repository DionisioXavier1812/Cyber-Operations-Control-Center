# Cyber Operations Control Center v1.0

## Overview

Cyber Operations Control Center (COCC) é um ambiente integrado de estudo, documentação e simulação de operações cibernéticas.

O projeto reúne capacidades de:

- Governance
- SOC
- DFIR
- Threat Intelligence
- Critical Infrastructure Security
- Strategic Defense
